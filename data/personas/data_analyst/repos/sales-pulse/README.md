# sales-pulse

Star-schema model, DAX measures for YoY and margin, and row-level security per region. Built with Power BI, SQL.

## Features
- Extract-transform-load pipelines
- Advanced excel modelling (pivots, power query)
- Power bi dashboards and dax
- Complex analytical sql (window functions, ctes)

## Running
```bash
make dev
```

_Context: retail project, 2024-04._
