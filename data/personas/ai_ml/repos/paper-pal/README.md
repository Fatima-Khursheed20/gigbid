# paper-pal

Open-source tool with section-aware chunking, reranking and answer-faithfulness checks. Built with RAG, FAISS, LLM evaluation.

## Features
- In-memory approximate nearest-neighbour search
- Systematic evaluation of llm outputs
- Llm application orchestration
- Strong python engineering

## Running
```bash
make dev
```

_Context: education project, 2025-09._
