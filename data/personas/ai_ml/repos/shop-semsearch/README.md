# shop-semsearch

Embedded 80k products with a sentence-transformer and served vector search with keyword fallback. Built with Pinecone, Python.

## Features
- Serving models behind a typed rest api
- Fine-tuning pretrained transformer models
- Managed vector database for similarity search
- Strong python engineering

## Running
```bash
make dev
```

_Context: ecommerce project, 2024-05._
