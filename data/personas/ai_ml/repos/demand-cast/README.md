# demand-cast

Combined a seasonal forecaster with a gradient-boosted residual model, refreshed nightly. Built with Prophet, Python, XGBoost.

## Features
- Scheduled data pipelines (dags)
- Time-series forecasting with seasonality
- Strong python engineering
- Gradient-boosted tree models

## Running
```bash
make dev
```

_Context: retail project, 2024-02._
