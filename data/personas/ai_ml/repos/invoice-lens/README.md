# invoice-lens

OCR with image deskewing, then entity extraction for vendor, totals, dates and tax IDs. Built with Tesseract OCR, spaCy, Python.

## Features
- Serving models behind a typed rest api
- Classical image processing
- Strong python engineering
- Ocr of scanned documents

## Running
```bash
make dev
```

_Context: fintech project, 2024-09._
