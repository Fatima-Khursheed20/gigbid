# Legacy jQuery to React migration

*Client:* SecureLife Insurance · *Industry:* insurance · *Delivered:* 2024-10

## The problem
A 9-year-old quoting UI was impossible to change safely.

## What I built
Incremental strangler migration screen by screen behind feature flags. Under the hood this involved automated build and deploy pipelines.

## Results
Migrated 42 screens with zero downtime; bug reports down 55%.

## Stack
React, TypeScript, Jest and a few internal libraries.
