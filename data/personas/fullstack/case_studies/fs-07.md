# E2E test suite for a checkout

*Client:* Bazaar Mart · *Industry:* ecommerce · *Delivered:* 2025-01

## The problem
Every release broke something in checkout.

## What I built
120 end-to-end scenarios running in parallel on every pull request with visual diffs. Under the hood this involved automated build and deploy pipelines.

## Results
Checkout incidents after release fell from 6 per quarter to 0 over two quarters.

## Stack
Playwright, TypeScript.
