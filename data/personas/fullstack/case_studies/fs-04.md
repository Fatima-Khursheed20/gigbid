# GraphQL API for a news app

*Client:* Daily Ledger · *Industry:* media · *Delivered:* 2024-01

## The problem
Mobile and web clients made 14 REST calls to render one screen.

## What I built
Single GraphQL schema with dataloaders and per-field caching. Under the hood this involved caching and pub/sub, containerised deployments.

## Results
Home-screen load time from 3.2 s to 0.9 s; backend costs down 30%.

## Stack
GraphQL, Node.js, MongoDB.
